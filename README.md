# ЗаказРадар

Telegram-бот для фрилансеров: читает ленту новых заказов FL.ru и присылает те, что подходят под фильтры пользователя.
Бот ничего не отправляет на FL.ru сам: отклик человек пишет и отправляет сам.

```
FL.ru RSS (раз в 2–3 мин) → база заказов за 14 дней (дедупликация по ссылке)
    → 📡 Радар: подходящие заказы приходят в чат (PRO сразу, FREE через 30 мин)
    → 🔎 Поиск по базе · карточка заказа · ✍️ шаблон отклика · ⭐ избранное
```

## Запуск локально

```bash
python -m venv .venv
.venv\Scripts\pip install -r requirements-dev.txt     # Linux/macOS: .venv/bin/pip
copy .env.example .env                                # впиши BOT_TOKEN и ADMIN_IDS
.venv\Scripts\python main.py
```

При первом запуске (база пустая) бот один раз читает ленты всех категорий с паузой в 1 секунду
(около 25 секунд). После этого в поиске сразу есть заказы примерно за 14 дней. Дальше он опрашивает только общую ленту.

Проверка без Telegram:

```bash
.venv\Scripts\python -m pytest                           # все тесты, включая обход всех кнопок
.venv\Scripts\python -m radar.devtools.live_check        # реальная лента: «Программирование» + «телеграм, бот»
```

## Источник данных

- `https://www.fl.ru/rss/all.xml` содержит 60 последних заказов. Поля: title, link, description (около 180 символов), category, pubDate.
- Бюджет берётся из конца названия: «(Бюджет: 20 000 ₽)». Он есть не у всех заказов.
- Категория определяется по тексту `<category>` самого заказа, потому что неверный `?category=` молча отдаёт общую ленту.
  У заказа может быть несколько категорий.
- Опрос раз в `POLL_SECONDS` (по умолчанию 150 с). User-Agent честный, таймаут 25 с, при ошибках пауза растёт ×2 до 30 мин.
  Если успешных опросов нет больше 15 минут, админ получает уведомление, а после восстановления ещё одно.
- Заказы старше 14 дней удаляются. Заказы из чьего-то избранного остаются.

## Тарифы — `config/plans.json`

| | FREE | PRO неделя / месяц |
|---|---|---|
| Поиск | 3 поиска всего | без лимита |
| Радар | задержка 30 мин, до 10 в день | сразу, без лимита |
| Категории / слова | 1 / до 3 | без лимита |
| Фильтр по бюджету, свои шаблоны | — | ✅ |
| Цена | 0 | 49 ⭐ / 149 ⭐ |

Повтор того же поиска и пустой поиск бесплатные поиски не списывают. Оплата идёт звёздами Telegram, один платёж
зачисляется ровно один раз. Пользователи из `ADMIN_IDS` получают PRO навсегда без оплаты.

## Админ

`/admin` показывает пользователей, PRO, новые заказы за сутки, статус ленты и воронку (start → фильтры → поиск → счёт → оплата).
Команды: `/grant ID ДНЕЙ`, `/refund CHARGE_ID`, `/user ID`, `/broadcast ТЕКСТ` (рассылка с подтверждением).
Поддержка: пользователь пишет в `/support`, админ отвечает Reply на пересланное сообщение.

## Деплой на BotHost (из GitHub)

1. Подключи репозиторий `zakaz-radar`, ветку `main`.
2. Язык Python 3.10 или новее, главный файл `main.py`, зависимости из `requirements.txt`.
3. Переменные окружения: `BOT_TOKEN`, `ADMIN_IDS`, `SUPPORT_CONTACT`, `PAYMENTS_ENABLED=true`.
4. База лежит в `data/radar.db`, в git она не попадает. Если у BotHost есть постоянный диск, укажи путь на нём
   через `DB_PATH`, иначе при пересборке сбросятся пользователи и подписки.

## Структура

```
main.py                 точка входа (python main.py)
radar/fl.py             категории, загрузка и разбор RSS
radar/matching.py       фильтры: категории, слова (по началу слова), исключения, бюджет
radar/services/         заказы и Радар, лимиты, оплата Stars, избранное/статистика/воронка
radar/bot/              экраны (views.py), обработчики, фоновые задачи (jobs.py)
radar/devtools/         симулятор Telegram (из Leadly), live_check
tests/                  pytest, сохранённый образец ленты в tests/data
```
